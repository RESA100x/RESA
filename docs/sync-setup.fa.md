# سینک آنلاین RESA — راهنمای راه‌اندازی

RESA آفلاین‌محور است: SQLite منبع حقیقت است و همهٔ ماژول‌ها بدون حساب و بدون
اینترنت کامل کار می‌کنند. سینک یک قابلیت **اختیاری** است که فقط وقتی روشن
می‌شود که کاربر در «تنظیمات ← سینک آنلاین» سرور را تنظیم کند، حساب بسازد و
کلید سینک خودکار را بزند.

## سمت کلاینت (آماده است)

- جدول‌های سینک‌شونده: تقویم و استثناهای تکرار، وظایف، مراحل وظیفه، لِین‌های
  کانبان، برچسب‌ها و لینک برچسب، پروژه‌ها، یادداشت‌ها، جلسات (و حاضران و
  دستور کار)، دفتر تلفن و دسته‌بندی‌ها، کتابخانه، گیاهان، جلسات تمرکز و
  قالب‌های سفارشی.
- هر جدول سه تریگر دارد (درج/ویرایش/حذف) که تغییر را در `sync_outbox` می‌گذارد.
  جدول‌هایی که در یک فضای کاری وجود ندارند نادیده گرفته می‌شوند.
- موتور سینک اول push می‌کند بعد pull، با حل اختلاف «آخرین نویسنده برنده» بر
  اساس `updated_at` و شمارندهٔ `server_updated_at` برای pull.
- سینک خودکار هر ۲ دقیقه، هم در ویندوز و هم در اندروید.
- ثبت‌نام با ایمیل + رمز و شمارهٔ موبایل اختیاری (فعلاً به‌عنوان فرادادهٔ
  پروفایل ذخیره می‌شود)، ارسال دوبارهٔ ایمیل تأیید، و ورود/خروج.

## سمت سرور (وقتی VPS آماده شد)

1. یک پروژهٔ Arianet BaaS بسازید (PostgreSQL مدیریت‌شده + Auth + REST).
2. فایل `src-tauri/migrations/baas/0001_sync.sql` را روی همان پروژه اجرا کنید
   (SQL Editor پنل یا `arianet baas db push`). این فایل جدول
   `public.sync_records`، سیاست RLS «فقط صاحب ردیف» و تابع `sync_push` را
   می‌سازد و تکرارپذیر است.
3. در تنظیمات Auth، تأیید ایمیل را روشن و SMTP را ست کنید. تا وقتی ایمیل تأیید
   نشود، ورود انجام نمی‌شود و کلاینت پیام روشن می‌دهد.
4. `Endpoint` پروژه و `anon key` را از صفحهٔ API Keys بردارید و در برنامه
   وارد کنید.
5. در برنامه ثبت‌نام کنید، ایمیل را تأیید کنید، بعد «سینک خودکار» را روشن کنید.

## تأیید پیامکی (مرحلهٔ بعد)

Supabase Auth برای شمارهٔ موبایل فقط با درگاه‌های خارجی کار می‌کند. برای ایران
باید یک Edge Function بسازیم که کد یک‌بارمصرف بسازد و با درگاه پیامک
(کاوه‌نگار / SMS.ir / API پیامک آریانت) بفرستد و تأیید کند، سپس شماره را در
پروفایل علامت بزند. تا آن زمان شماره فقط ذخیره می‌شود.

## نکته‌های عملی

- Realtime آریانت هنوز «به‌زودی» است؛ سینک دوره‌ای است، نه لحظه‌ای.
- فایل‌ها (تصویر جلد کتاب، استیکر، پیوست) سینک نمی‌شوند؛ فقط دادهٔ متنی.
- اگر روی یک دستگاه داده پاک شود و همان رکورد روی دستگاه دیگر باشد، حذف
  منتشر می‌شود؛ پس بکاپ دوره‌ای را نگه دارید.
