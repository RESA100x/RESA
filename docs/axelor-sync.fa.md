# اتصال تقویم RESA به Axelor

RESA می‌تواند تسک‌ها و برنامه‌های یک سرور **Axelor** را بخواند و کنار تقویم محلی
نمایش دهد. این اتصال از REST خود Axelor استفاده می‌کند، نه از دیتابیس آن؛ بنابراین
هیچ دسترسی مستقیمی به PostgreSQL/MySQL لازم نیست و مجوزها همان مجوزهای کاربر
Axelor باقی می‌مانند.

## چه چیزی همگام می‌شود؟

- هر مدل Axelor که کلید API به آن دسترسی دارد (پیش‌فرض:
  `com.axelor.apps.project.db.ProjectTask`).
- فیلدهای خوانده‌شده: عنوان (`name`/`subject`/`title`)، شروع
  (`plannedStartDate`/`startDateTime`/`startDate`/`fromDate`/`date`)، پایان
  (`plannedEndDate`/`endDateTime`/`endDate`/`toDate`/`dueDate`/`deadline`)،
  توضیحات، محل، و نام مسئول/پروژه (به توضیح رویداد اضافه می‌شود).
- رکوردهایی که تاریخ شروع ندارند نمایش داده نمی‌شوند؛ در Axelor این‌ها
  «بدون برنامه» هستند و جای مشخصی روی تقویم ندارند.

این نسخه **فقط خواندنی** است: تغییر در RESA به Axelor نوشته نمی‌شود.

## پیش‌نیازها

1. سرور Axelor در دسترس باشد (دامنه با HTTPS، یا آدرس داخلی/`localhost`).
2. در Axelor یک **API key** بسازید و به کاربری بدهید که حداقل دسترسی خواندن به
   مدل موردنظر را دارد.
3. ماژول مربوطه (مثلاً Project) نصب و فعال باشد؛ در غیر این صورت مدل آن وجود ندارد.

## مراحل در RESA

1. تنظیمات ← اشتراک‌های تقویم ← منبع: **Axelor (REST)**.
2. «نشانی سرور Axelor» را وارد کنید، مثل `https://axelor.example.com` یا
   `http://192.168.1.20:8080`.
3. «کلید API» را وارد کنید (رمزنگاری‌شده با DPAPI روی همین دستگاه ذخیره می‌شود).
4. «اتصال و دریافت مدل‌ها» را بزنید؛ فهرست مدل‌های مجاز از `/ws/meta/models` می‌آید.
5. مدل را انتخاب کنید، نام و دسته را تعیین کنید و «افزودن اشتراک» را بزنید.
   اولین همگام‌سازی بلافاصله اجرا می‌شود و بعد با بازه‌ای که انتخاب کرده‌اید
   (۱ تا ۳۰ دقیقه) تکرار می‌شود.

## نکات امنیتی

- آدرس سرور را خودتان وارد می‌کنید؛ به همین دلیل آدرس‌های داخلی (LAN) مجازند،
  ولی `http` فقط برای آدرس‌های داخلی/`localhost` پذیرفته می‌شود و سرورهای عمومی
  باید `https` باشند.
- درخواست‌ها redirect را دنبال نمی‌کنند، زمان‌محدود دارند و حجم پاسخ محدود است.
- کلید API هرگز به رابط کاربری برنمی‌گردد و در فایل دیتابیس به‌صورت رمزشده است.

## عیب‌یابی

| نشانه | علت احتمالی |
| --- | --- |
| «Axelor دسترسی را رد کرد» | کلید API نامعتبر است یا کاربر دسترسی خواندن ندارد |
| «هیچ مدلی برنگشت» | کلید فقط به مدل‌های محدودی دسترسی دارد یا ماژول نصب نیست |
| «Axelor پیدا نشد» | آدرس اشتباه است یا سرور از این شبکه در دسترس نیست |
| مدل هست ولی رویدادی نمی‌آید | رکوردها تاریخ شروع ندارند یا در بازه تقویم نیستند |
